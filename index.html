-checkall · v2.2.0-vanteam.2

Every error of every module, in one run

On 1C modules oscript -check nearly always meets a name OneScript does not have — Справочники, Документы, a common module — and stops. OneScript 2.x parses the whole module first, so syntax is still checked in full, but the code generator checks after that point never run: argument count of the module's own methods, a procedure used as a function, a duplicate method, labels. OneScript 1.9.4 compiles in one pass and sees nothing at all after the first unknown name. Each -check also starts the engine: about 0.7 s of 0.9 s per file.

-checkall starts the engine once for all files, collects errors instead of stopping at the first, and lists unknown names separately. -check itself is unchanged. The 2.2.0-vanteam.2 build is also published with ReadyToRun.

OneScript defines no 1C preprocessor symbols, so code under #Если Сервер Тогда is an inactive branch and is skipped by any mode. To check it, also pass a copy of the module with the directive lines blanked out; line numbers stay the same.

The bug

A flag that never resets

When an #Если condition is false, the preprocessor skips the branch and looks for the next #. It trusted the iterator's OnNewLine, which only changes when a lexeme is read — so it stayed true for the whole skipped branch, and any # became a directive.
